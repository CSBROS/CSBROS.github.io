# Nana Owusu Research Lab

Source for **https://csbros.github.io**: an interactive record of pre-registered research on S&P 500 and Nasdaq-100 futures.

- `index.html` — the research lab (static HTML and vanilla JS, no build step)
- `tools/rr-matrix/` — the R:R Expectancy Matrix

Study write-ups and code: https://github.com/CSBROS/research

To switch on the LinkedIn and email links, edit the `SITE` object at the top of the script in `index.html`.
